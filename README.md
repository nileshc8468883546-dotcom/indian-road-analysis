# indian-road-analysi## 🚗 Indian Road Accident Analysis Dashboard | Power BI

 ### 📌 Project Overview

 Developed an interactive **Power BI dashboard** to analyze Indian road accident data and identify patterns across states, road types, traffic density, accident severity, risk levels, and accident causes. The dashboard covers **20,000 accidents and 34,529 casualties** and uses interactive filters for **State, Risk Category, Time Period, and Road Type** to make the analysis easy to explore.

 ### 🔍 Key Insights

 - **Maharashtra** recorded the highest number of accidents among the states analyzed.
- Accident records were compared across **High, Medium, and Low traffic-density** categories.
- **Urban, rural, and highway** accident patterns were analyzed separately.
- Accident severity was categorized into **Fatal, Major, and Minor**.
- **Distraction and overspeeding** appeared among the leading recorded accident causes.
- The dashboard provides an overall **average risk score of 0.438**.
- The analysis highlights how accident patterns can vary based on **location, road type, traffic density, and cause**.
